**Навчальний проєкт | Data Science Club**

Цей репозиторій містить рішення практичного завдання з побудови повного циклу обробки даних (ML Pipeline) для класифікації доходів населення.

## Опис проєкту
Мета роботи — пройти шлях від «сирих» даних до готової моделі машинного навчання, використовуючи сучасні інструменти автоматизації (Scikit-Learn Pipelines). 

**Набір даних:** [Adult Census Income](https://www.kaggle.com/datasets/uciml/adult-census-income) 
* **Основні бібліотеки:** `pandas`, `numpy`, `matplotlib`, `seaborn`.
* **ML інструменти:** `scikit-learn`, `imbalanced-learn` (SMOTE).

## Структура ноутбука
1. **0. Підготовка:** Імпорт бібліотек та ініціалізація класу `EvaluateModel` для уніфікованої оцінки результатів.
2. **1. Завантаження даних:** Зчитування та первинний огляд датасету.
3. **2. EDA (Аналіз даних):** Дослідження ознак, візуалізація розподілів та пошук кореляцій.
4. **3. Створення Baseline:** Побудова базової моделі на мінімально оброблених даних для порівняння.
5. **4. Full Pipeline:** Реалізація автоматизованої обробки (Scaling для числових ознак та OneHotEncoding для категоріальних).
6. **5. SMOTE Pipeline:** Додавання стратегії балансування класів для покращення метрик на меншості.
7. **6. Порівняння результатів:** Фінальна таблиця з метриками Accuracy, Precision, Recall та F1-score.
